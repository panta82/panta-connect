# Publish a release

The public source repository is `panta82/panta-connect`. GitHub Pages serves `https://panta82.github.io/panta-connect/`, with the signed F-Droid repository under `repo/`. GitHub receives only public source and already signed binaries and indexes. Both private signing keys stay on the release machine.

1. Increase `versionCode` and `versionName` in `build.gradle.kts` and the current version in `fdroid/metadata/net.pantas.connect.yml`. Build and test with JDK 21 and the required Android SDK, using `run-tests './gradlew --no-daemon --max-workers=1 --no-parallel testDebugUnitTest assembleRelease'` on the development host. Configure the private release signing properties as described in the main README.
2. Test the signed build and an upgrade on the Xperia. Verify desktop screenshot to Gboard Image suggestion to X attachment without publishing. Preserve the fork pairing. Keep Jelly Max on its existing setup until the release candidate is ready.
3. With the tested source unchanged, run `python3 tools/stage_fdroid.py build/outputs/apk/release/kdeconnect-android-release.apk --repo-url https://panta82.github.io/panta-connect/repo`. Inspect `build/fdroid-public/`. It must contain only the landing page and public repository files. Never upload private configuration, keystores, local status reports, device screenshots, or the private F-Droid working directory.
4. Commit the release source on the existing branch and tag it with the release version. Attach the staged APK and its corresponding source archive to a GitHub release. Also bundle the complete `build/fdroid-public/` directory as `panta-connect-fdroid.tar.gz` with its SHA-256 in `panta-connect-fdroid.tar.gz.sha256`. The checksum line must use that filename without a directory prefix.
5. Publish the release. The Pages workflow downloads the signed repository bundle and deploys it. It does not build or sign Android packages. A manual workflow run can redeploy a selected release. Check that the public APK and signed indexes match the local files, then add the public HTTPS repository in F-Droid on Xperia and confirm it recognizes the installed release.
